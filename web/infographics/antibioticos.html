🧭 Elección empírica por síndrome · Empiric choice

  • NAC ambulatorio sano: amoxicilina dosis alta o doxiciclina.
  • NAC hospitalizado: β-lactámico (ceftriaxona) + macrólido, o FQ respiratoria.
  • Cistitis: nitrofurantoína, fosfomicina o TMP-SMX.
  • Pielonefritis: FQ o ceftriaxona.
  • Celulitis no purulenta: cefazolina / cefalexina.
  • Purulenta (MRSA): drenaje + TMP-SMX o doxiciclina.
  • Intraabdominal: pip-tazo o carbapenem; o ceftriaxona + metronidazol.
  • Meningitis adulto: ceftriaxona + vancomicina (+ ampicilina si >50a) + dexametasona.

🧠 Mnemónicos · Mnemonics

Anti-Pseudomonas: Pip-tazo, Ceftazidima, Cefepime, Aztreonam, Carbapenems (≠ erta), FQ, Aminoglucósidos.

Anti-MRSA: Vanco, Linezolid, Dapto, Ceftarolina, Clinda, Cotri, Doxi.

Anaerobios: arriba del diafragma → Clinda; abajo → Metro.

Atípicos (MQT): Macrólidos, Quinolonas, Tetraciclinas.

💡 Perlas · Pearls

  • Quien cubre Pseudomonas casi nunca cubre MRSA → en sepsis a veces necesitas ambos.
  • Daptomicina ≠ pulmón (surfactante la inactiva).
  • Ertapenem ≠ Pseudomonas.
  • Vancomicina oral solo para C. difficile.
  • Desescala con cultivo a las 48–72 h (WHO AWaRe).

🚩 Banderas rojas · Red flags

  • Embarazo: evitar FQ, tetraciclinas; sulfas/nitrofurantoína cerca del término.
  • FQ: tendón/aorta/QT/disglucemia.
  • Aminoglucósidos: nefro + ototoxicidad.
  • Vancomicina: "hombre rojo", nefrotoxicidad.
  • Alergia grave a penicilina: aztreonam para Gram−.
